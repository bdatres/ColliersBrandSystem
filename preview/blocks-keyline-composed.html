Blocks + keyline · how they interact (optional — apply only where it fits the composition)

Blocks and keylines together define the main composition of our layouts, serving as branding elements that lead the viewer's attention to our messaging. This is a situational reference, not a required pattern — they interact in three core ways when used together.

Overlapping

A keyline can overlap a block, as long as it isn't the same color and tint as the overlapped block.

Gap space

Keylines break before and after an overlapping block — the gap equals half the margin space for the keyline.

Frame color

The frame can be one color, or switch colors as it leads into a darker / lighter background or photo.

Size & orientation: no firm rules on proportion — but when two blocks are used, one should be larger (≥ 3:1) and they must overlap. Single blocks can be anchored to an edge or float anywhere on the canvas.
